# Cribl Decision 1.0 plays Doom: benchmark report

_Generated by `report.py` from `results/benchmarks/*.json` and `results/traces/*.csv`._

**Hardware / software:** Apple M4 Pro, 24 GB unified memory, Darwin 26.7, Python 3.12.13; vizdoom 1.3.1, mlx 0.32.3, mlx-lm 0.32.0, torch 2.14.1, transformers 5.19.0, peft 0.21.2

**Cribl configuration:** backend `mlx-metal`, dtype `bfloat16`, format `plain_letter_qfirst`, criteria `rule`, 4 tics per decision, seeds 1234…1253.

Kills come from the engine's KILLCOUNT. Reward is the scenario's score: +1 per kill and −1 for dying, which is the number the original project's table calls kills. Hit rate is HITCOUNT over shots fired. Latency is wall-clock time per decision, including prompt building. Game speed is seconds of game time per second of wall clock (1.0 = real time).
